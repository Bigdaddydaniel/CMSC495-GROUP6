# Group 6 Peer Review Checklist

Reviewer should verify:

- Code is readable, named consistently, and separated by responsibility.
- User input is validated and unsafe operations are escalated.
- Secrets are not hardcoded and production authentication is identified as required technical debt.
- AI/retrieval work does not block or duplicate unnecessary processing.
- API objects match the interface contract and integrate with conversation/ticket modules.
- README and endpoint documentation are clear enough for another teammate to run the Alpha.
- Tests cover a grounded answer, a human handoff, and an unknown request.
